# pdf-viewer

紙の本を物理的に扱う感覚でページをめくる、3D 本型 PDF ビューアです。
描画は **SDL3 の GPU レンダラー**（macOS では Metal）で行い、OpenGL は使いません。

- 左綴じの本を机の上に置いたような 3D 表示
- 右のページ束 / 左のページ束を「掴む」「離す」
- 掴んだ束を扇状に持ち上げ、離すとページが順にめくれる
- PDF は macOS の CoreGraphics でラスタライズ
- PDF を指定しない場合は 24 ページのデモ本を表示

## ビルド

macOS を想定しています。

```sh
brew install sdl3 pkg-config
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

```sh
./build/pdf-viewer                 # デモ本
./build/pdf-viewer --demo          # デモ本
./build/pdf-viewer path/to/book.pdf
```

## 操作

| キー | 動作 |
| --- | --- |
| `S` | 左手で左のページ束を掴む / 離す（トグル） |
| `K` | 右手で右のページ束を掴む / 離す（トグル） |
| `A` | 左の掴む枚数を減らす（1〜8 を循環） |
| `L` | 右の掴む枚数を減らす（1〜8 を循環） |
| `J` | 右から中央（左）へ 1 ページ送る。`L` の設定に影響されない |
| `D` | 左から中央（右）へ 1 ページ送る。`A` の設定に影響されない |
| `M` | 1 ページ進む |
| `C` | 1 ページ戻る |
| `Q` / `Esc` | 終了 |

### 掴みの考え方

- `K` を押すと、右のページ束の上から `RIGHT GRIP` 枚を掴みます。
- 掴んでいる間はページが少し浮き、束が扇状に分かれます。
- もう一度 `K` を押すと離し、掴んでいた枚数だけ右から左へページが送られます。
- `L` は「次に掴む枚数」を減らします。1 の次は 8 に戻ります。
- 左側も `S` / `A` で左右対称に操作できます。
- 片方の手で掴んでいる間は、もう片方の手の掴みやページ送りは受け付けません。
  本の束の順序が壊れないようにするためです。

`J` / `D` は掴み枚数と無関係に 1 ページだけ送る「はじき」操作です。
`M` / `C` は通常の 1 ページ送りです。

## 構成

```
src/
  main.cpp              SDL3 の起動、入力、メインループ
  book.hpp/.cpp         ページ束の論理状態と、掴み・離し・めくりのアニメーション
  renderer.hpp/.cpp     SDL3 GPU レンダラー。CPU で 3D 投影して SDL_RenderGeometry で描画
  page_source.hpp       ページ画像ソースの抽象
  demo_source.cpp       デモ本のページ生成
  pdf_source_macos.mm   CoreGraphics による PDF ページのラスタライズ（macOS）
  pdf_source_stub.cpp   PDF 非対応プラットフォーム用
  math3d.hpp            4x4 行列、ベクトル、透視投影
  bitmap_font.hpp       5x7 の内蔵ビットマップフォント
```

### ページめくりの回転

`rotation.cpp` の「回転を状態ではなく、軸・角度・補間・合成の段として扱う」考え方を
参考にしています。ページは綴じ目（spine）を軸に回転し、`turn` を 0（右）から
1（左）へ補間します。ページの法線は頂点ごとに計算し、しなり（bow）も頂点変形として
入れています。順序は

```
local page (bow 込み) -> rotateY(spine) -> translate(lift) -> rotateX(lay flat) -> scale(book)
```

で、合成順序を崩さないようにしています。

### 描画について

- 深度バッファは使わず、ページを奥から手前へ並べて描画するペインターズアルゴリズムです。
- `SDL_RenderGeometry` のテクスチャ補間はアフィンなので、ページを 24x4 に分割して
  遠近の歪みを抑えています。
- ページ束の厚みは、個々のページを何百枚も描かず、縦縞のあるページ断面ブロックで表現します。
- UI は 5x7 フォントのアトラスを `SDL_RenderGeometry` で描いています。
- 論理画面は 1280x800 固定で、ウィンドウのリサイズ時は SDL のレターボックスで拡大縮小します。

## 制限

- PDF の直接読み込みは macOS のみです。それ以外ではデモ本になります。
- PDF のページは 1000px 高でキャッシュします（最大 32 ページ）。
- 一度に掴めるのは 8 ページまでです。
- 片手ずつ操作する前提です。
